# Bank Management System (Java)

A simple Java console-based Bank Management System built using OOP principles.  
This project is designed to practice core Java concepts like encapsulation, classes, objects, and relationships between entities.

## Features (Planned)

- Create customer
- Create bank account
- Deposit money
- Withdraw money
- Transfer money
- View account details

## Tech Stack

- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA (or any Java IDE)
- Git & GitHub

## What I Learned

- Encapsulation
- Constructors
- Object composition (Customer → Account relationship)
- toString() method
- final keyword
- Basic Git workflow
